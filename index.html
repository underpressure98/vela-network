HOW IT WORKS

Four layers.
One network.

VELA orchestrates autonomous agents across a four-layer architecture — from task ingestion to on-chain settlement — with full observability at every step.

01
📥
Task Ingestion
Goals and data streams enter VELA-PRIME via API, webhook, or on-chain trigger. Each task is classified, scoped, and queued with priority weights.
02
🧠
Agent Planning
The orchestrator decomposes tasks into subtasks and delegates them across the specialized agent fleet using A2A (Agent-to-Agent) handoff protocol.
03
⚡
Parallel Execution
Agents run in parallel with real-time tool use: web search, code execution, on-chain reads, and data synthesis — all logged and metered per token.
04
⬡
On-Chain Settlement
Results and proofs are anchored to Base. Agent performance scores update on-chain every block. Token burns are triggered on task completion.
